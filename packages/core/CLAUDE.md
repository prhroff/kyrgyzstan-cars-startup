# packages/core

Перед работой с ценами, телефонами, VIN, валютами прочитай `docs/domain.md`.

- Без зависимостей от БД и Prisma — только чистые функции, zod, типы.
- `src/enums.ts` — единый источник значений enum'ов; Prisma-enum'ы зеркалят его
  (тест `packages/db/src/enums.test.ts`).
- Префиксы операторов — только в `src/phone/kg-operators.ts`.
- Каждая функция — с тестом рядом (`*.test.ts`); граничные и невалидные случаи обязательны.
- Утилиты не бросают на мусорный ввод — возвращают `null` (или `{ valid: false }` для VIN).
- Не писать `\uXXXX` в файлы через инструменты записи — они превращаются в литералы; используй
  `String.fromCodePoint(...)` или `\s` в regex.
- Новый экспорт — добавить в `src/index.ts`.
- Тесты: `pnpm --filter @repo/core test [файл]`.
