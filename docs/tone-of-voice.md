# Tone of voice

Говорим как знающий друг, который разбирается в машинах: спокойно, по делу, без давления.
Основа — принципы UX-редакции Авито (не врать, без канцелярита и штампов, кнопка = действие,
нейтрально для массовой аудитории). Наше отличие — каждое утверждение опирается на источник.

## Принципы

1. **На «вы», с маленькой буквы.** Аудитория — от студентов до пенсионеров, плюс дилеры. Одна форма везде.
2. **Коротко.** Одна мысль — одна фраза. Заголовок до 5 слов, пояснение — 1–2 предложения.
   Не дублируем заголовок в пояснении и пояснение в кнопке.
3. **Простыми словами, без канцелярита.** Глагол вместо отглагольного существительного.
   - Так: «Укажите пробег». Не так: «Необходимо осуществить ввод пробега».
4. **Кнопка говорит, что произойдёт.** Глагол + объект, если без объекта непонятно.
   - Так: «Показать телефон», «Подать объявление». Не так: «Позвонить» (если звонок не начнётся), «Далее», «ОК».
   - Без эмоциональных призывов: не «Хочу купить!», «Скорее смотреть».
5. **Ошибка = что случилось + как исправить.** Без вины пользователя и без кодов.
   - Так: «Год «от» должен быть не позже года «до»». Не так: «Неверный ввод», «Ошибка 422».
   - Не утверждаем причину, которую не знаем: «Возможно, пропал интернет», а не «Нет интернета».
6. **Пустое состояние — что делать дальше.** Заголовок-факт + совет + действие.
   - Так: «Ничего не нашли» · «Попробуйте убрать часть фильтров» · [Сбросить фильтры].
7. **Без давления и манипуляций.** Ни «Успейте!», ни «Цена скоро вырастет», ни «Осталось 2 часа».
   Не обещаем простоты там, где сделка сложная: покупка авто — серьёзное решение.
8. **Без шуток, отсылок, сленга и игры слов в интерфейсе.** Их не поймут все и не переведут.
9. **Грамотность:** «ёлочки», длинное тире, «ё» везде («ещё», «импортёр»), неразрывный пробел в «15 500 $».

## Доверие: факты, а не оценки

Мы сообщаем, **что найдено и где**, а вывод делает покупатель. У факта — источник и дата.

| Так                                                              | Не так                          |
| ---------------------------------------------------------------- | ------------------------------- |
| Найдена запись аукциона Copart, 2023: повреждение передней части | Машина битая                    |
| Пробег в объявлении меньше, чем в записи техосмотра 2022 года    | Пробег скручен                  |
| Цена на 18% ниже похожих объявлений за 30 дней                   | Подозрительно дёшево, осторожно |
| VIN не указан продавцом                                          | Продавец скрывает VIN           |
| Выше рынка                                                       | Дорого, переплата               |

- **Красные флаги** — нейтральный тон (`warning`, не `danger`), без слов «обман», «мошенник»,
  «скрывает», «подозрительно». Продавец мог не знать — не обвиняем.
- **«Нет данных» пишем честно** и не превращаем в «нет»:
  - Так: «Растаможка: нет данных». Не так: «Не растаможен» (если продавец не указал).
  - Так: «Записей не нашли в: <источники>». Не так: «История чистая», «Не битая».
    Отсутствие записи ≠ отсутствие события.
- **Не обещаем гарантий, которых не даём.** Мы не проверяем машину вживую и не отвечаем за сделку.
  - «Проверено», «осмотрено» — только если проверка реально была, и всегда с тем, кто и когда:
    «Осмотрено на СТО «…», 12 ноября». Без этого — запрещено.
  - Слово «гарантия» (и «гарантируем») — запрещено всегда.
  - Так: «VIN совпадает с данными <источник>». Не так: «Проверено», «Гарантия чистоты», «Надёжный продавец».
  - Так: «На сайте с марта 2026, 4 объявления». Не так: «Проверенный дилер» (пока нет проверки).
  - Совет вместо гарантии: «Перед покупкой проверьте машину на СТО».
- **Риски и безопасность** — спокойно и конкретно: «Не переводите предоплату до осмотра машины»,
  а не «Мошенники повсюду!».

## Деньги

- Основная валюта объявления — как у продавца; вторая — с «≈» и курсом в подсказке.
  Формат — `src/lib/format.ts`: «15 500 $», «1 350 000 сом» (не «сомов», не «KGS», не «$15,500»).
- Без «всего», «лишь», «выгодно», «дёшево» рядом с ценой. Разница с рынком — в процентах или $.
- «Торг» — только если продавец указал. Неизвестно — ничего не пишем.

## Кыргызстан и перевод

- Простой литературный русский. Без московского сленга и жаргона: «тачка», «движок», «бэха», «топ», «огонь».
- Города и места — как принято в КР: «Бишкек», «Ош», «Джалал-Абад», «Иссык-Куль».
- Тексты пригодны для перевода на кыргызский: законченные фразы, без склейки строк из кусков
  («на сайте » + N + « дней» — только через функцию с плюрализацией), без идиом.
- Не вшиваем слова в картинки; единицы измерения — отдельно от числа в разметке.

## Словарь

| Используем                              | Не используем                                   |
| --------------------------------------- | ----------------------------------------------- |
| объявление                              | лот, пост, карточка (в тексте для пользователя) |
| продавец; частное лицо; дилер           | частник (в интерфейсе), барыга, перекуп         |
| машина, автомобиль, авто (в заголовках) | тачка, ласточка                                 |
| пробег, км                              | миля без пересчёта, «пробег по РК»              |
| растаможен / не растаможен / нет данных | «на учёте» вместо «растаможен», «чистый»        |
| ниже рынка / в рынке / выше рынка       | дёшево / дорого, «выгодная цена»                |
| нет данных                              | неизвестно (в фактах), прочерк без пояснения    |
| источник, запись, найдено               | доказано, подтверждено (если не проверяли сами) |
| VIN                                     | вин, ВИН                                        |
| подать объявление, снять с публикации   | разместить лот, удалить (если это снятие)       |
| хетчбэк                                 | хэтчбек                                         |
